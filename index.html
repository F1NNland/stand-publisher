Stand Publisher

An internal desktop tool for publishing Unity builds of exhibition stands to our own Google Drive folder.

Stand Publisher is a Windows command-line utility used by our developers. It packs a Unity build into a zip archive, uploads it to a Google Drive folder that we own, and updates a small JSON file that tells our exhibition stands which version to install. The stands then download the build when on-site staff run the update check.

Who it is for

Stand Publisher is not a public product. It is used only by the developers of F1NNland, who sign in with their own Google accounts.

How it uses Google Drive

After you sign in with Google, the tool works only inside the Drive folder that you configure and does the following there:

  • creates folders for projects;
  • uploads build archives;
  • writes version files;
  • lists and removes old builds.

It sends no data anywhere except Google, and it has no servers of its own.

Stand Publisher

Внутренняя утилита для выкладки Unity-билдов выставочных стендов в нашу папку на Google Диске.

Stand Publisher — консольная программа для Windows, которой пользуются наши разработчики. Она делает три вещи:

  • упаковывает Unity-билд в zip-архив;
  • загружает его в папку на Google Диске, которая принадлежит нам;
  • обновляет небольшой JSON-файл, по которому стенды узнают, какую версию ставить.

Стенды скачивают билд, когда сотрудники на месте запускают проверку обновлений.

Для кого

Stand Publisher — не публичный продукт. Им пользуются только разработчики F1NNland, входя под своими Google-аккаунтами.

Как программа работает с Google Диском

После входа через Google программа работает только внутри папки Диска, которую вы указали в настройках, и делает там следующее:

  • создаёт папки проектов;
  • загружает архивы билдов;
  • записывает файлы версий;
  • просматривает и удаляет старые билды.

Данные она отправляет только в Google, собственных серверов у неё нет.
